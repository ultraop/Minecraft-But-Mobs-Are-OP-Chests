# Datapack Status

The current Paper 26.3 build does not use or require a datapack. Mob interaction, loot generation, inventory persistence and death-drop replacement are handled by the Paper plugin JAR.

The unused datapack placeholder directory has been removed from this repository. Do not upload an old Mob Chests datapack ZIP to the world's datapacks folder.

Future configurable loot tables could be moved into a datapack, but that is not part of the current build.
