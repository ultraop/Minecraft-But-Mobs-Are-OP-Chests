# Commands

Root: `/mobchests` (alias: `/mobchest`).

| Command | Permission | Function |
|---|---|---|
| `/mobchests info` | `mobchests.use` | Show plugin information |
| `/mobchests help` | `mobchests.use` | Show command help |
| `/mobchests status` | `mobchests.use` | Show runtime status |
| `/mobchests reload` | `mobchests.admin` | Reload configuration |

Custom item catalogue, item give/list commands, and custom resource-pack support have been removed.
