# Commands

Root: `/mobchests` (alias: `/mobchest`).

## Implemented in scaffold

| Command | Permission | Function |
|---|---|---|
| /mobchests info | Everyone | One combined version/build/platform/feature info panel |
| /mobchests help | Everyone | Grouped command guide |
| /mobchests status | Everyone | Runtime and scaffold status |
| /mobchests reload | mobchests.admin | Reload configuration and messages |

## Planned commands

| Command | Permission | Planned function |
|---|---|---|
| /mobchests loot preview <mob> | admin | Inspect resolved loot pools |
| /mobchests loot test <mob> [rolls] | admin | Simulate loot for balancing |
| /mobchests legend [player] | use | Open Legend GUI |
| /mobchests points <player> | admin | Inspect points |
| /mobchests boss status [player] | use | View boss unlock progress |
| /mobchests admin reset <player> | admin | Reset progress with confirmation |

Planned commands are not active yet. Use gold/bold headings, green success, yellow planned/warnings and red errors. There is only one info/version command: /mobchests info.
