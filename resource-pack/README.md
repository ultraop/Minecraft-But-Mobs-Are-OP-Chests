# Liquid Gold Resource Pack

Minecraft Java 26.3 resource pack (format 97.1).

- Gives Liquid Gold Bucket its own pale yellow/golden bucket model.
- Provides eight golden fluid-level models for the server plugin's ItemDisplay overlays.
- Animates a softly rippling translucent gold liquid texture.
- Does not change the vanilla lava or water textures.

Install this ZIP in the client's resourcepacks folder and enable it. The Paper plugin performs all gameplay simulation; no client gameplay mod or datapack is used.
